## 한 줄

**차가 실제로 도착하는 쪽 길가, 눈에 띄는 곳 앞에서 만나게 해 주는 픽업 앱.**

- 운전자는 화면을 보지 않고 음성만 듣습니다.
- 태울 사람은 길을 건너 헤매지 않습니다.
- 도착 몇 분 전에는 앱이 알아서 전화를 겁니다.

## 왜 이걸 하나

- **위치 공유는 이미 많습니다.**
  - 카카오맵 친구위치, 카카오내비 공유, CarPlay·Android Auto의 도착 시간 공유가 있습니다.
  - 이번 대회에도 픽업·동행 출품작이 16건 있습니다(11/7 조사 기준).
  - 그래서 위치 공유는 "기본"이고, 팔 거리가 아닙니다 **[메모]**.
- **꼬이는 곳은 마지막 100m입니다** **[11/5][11/7]**.
  - 위치는 서로 보이는데 태울 사람이 길 건너편에 서 있으면, 운전자는 신호를 두 번 받거나 U턴하거나 블록을 한 바퀴 돕니다.
  - 처음 가는 곳이거나 길눈이 어두우면 더 그렇습니다.
  - 그러다 운전 중에 "어디야?" 전화를 하게 됩니다.
- **비어 있는 자리**
  - 경쟁작 14곳 README에는 "차가 오는 쪽을 고른다", "랜드마크로 정한다", "대중교통을 섞는다", "자동으로 전화한다"가 없었습니다.
  - 택시 앱(카카오T)의 탑승 위치 추천은 택시 전용입니다.
  - 11/5 사실 점검이 찾은 빈칸(만날 지점 정하기 + 도착 타이밍 자동화)과도 맞습니다.
- **차가 있어야 되는 기능입니다** **[11/7 0:51:45]**: 차의 경로와 진행 방향, 조수석 문·착좌 신호를 씁니다. 폰만으로는 할 수 없습니다.

## 누가 쓰나

- **운전자**: 역·병원·학원 앞에서 가족이나 친구를 태우는 사람. 특히 초행길이거나 길눈이 어두운 사람 **[메모]**
- **태울 사람**: 앱을 설치하지 않습니다. 링크를 열거나, 전화만 받아도 됩니다.
- **장면**
  - 퇴근길 역 앞에서 배우자 태우기
  - 학원 끝난 아이 태우기
  - 진료가 끝난 부모님 태우기
  - 처음 가는 동네에서 친구 태우기
  - 심사위원도 3~50대라 가족을 태우는 장면에 공감할 것이라는 말이 회의에 나왔습니다 **[11/7 0:15:57]**.
- **부문**: 모빌리티 라이프 케어. 공모전 설명에 "주문 · 픽업 · 주차"가 직접 나옵니다.

## 방향 세 가지와 고른 것

| 방향 | 무엇을 중심에 두나 | 판단 |
|---|---|---|
| **A. 같은 편 지점 (고름)** | 차가 오는 쪽 길가 + 랜드마크 + 세워도 되는 곳 | 아무도 안 하는 것이고, 회의에서 말한 불편 그대로입니다. 대중교통과 자동 전화는 이것을 돕는 기능으로 둡니다. |
| B. 대중교통 역마중 | 태울 사람이 한두 정거장 와서 만나기 | 시간이 크게 줄어드는 장면이 드뭅니다. 자동차·대중교통 경로 API가 둘 다 필요해 시연이 어렵습니다. |
| C. 완전 자동화 | 자동 전화·도착 감지·탑승 확인 | 마중(도착 시간, 준비 상태, 100m 안 도착 감지)과 가장 많이 겹칩니다. |

### 하지 않는 것

- **여러 명 픽업 순서**: PICKGO가 이미 합니다.
- **카풀 매칭**: 페어카가 이미 합니다.
- **앱이 직접 길 안내**: Pleos 단일 경로 정책과 충돌합니다. 고른 지점은 NaviHelper로 기본 내비에 넘깁니다.
- **주행 중 운전자에게 사진·지도 보여 주기**: 2초 규칙에 맞지 않습니다 [11/7 0:50:45]. 주행 중에는 음성만 씁니다.

## 같은 편 지점을 고르는 방법 (F1)

1. 태울 사람 위치에서 걸어서 300m 안의 눈에 띄는 곳을 모읍니다. 예: 역 출구, 병원, 은행, 편의점, 큰 카페. 사람을 저장할 때 아이·어르신으로 표시해 두면 150m 안에서만 찾습니다.
2. 차가 각 후보에 도착할 때의 마지막 진행 방향을 봅니다. 한국은 오른쪽 통행이라, 후보가 진행 방향 **오른쪽 길가**에 있어야 합니다. 마지막에 U턴이 들어가는 후보는 뺍니다.
3. 세우면 안 되는 곳을 뺍니다. 기준은 도로교통법 제32조입니다(교차로 모퉁이 5m 이내, 버스정류장·횡단보도 10m 이내 등). 구현 전에 조문을 다시 확인합니다.
4. 남은 후보를 이 순서로 고릅니다.
   - 만나는 시각이 빠른 곳: 차 도착과 사람 걸음 중 늦은 쪽 기준
   - 덜 걷는 곳
   - 길을 덜 건너는 곳
5. 고른 지점은 NaviHelper로 기본 내비 목적지에 넣습니다. 기본 내비가 반대쪽으로 데려가지 않게 두 가지를 합니다.
   - 지점 100m 앞 같은 차로에 진입 경유지를 넣습니다.
   - 300m 앞에서 실제 진행 방향(FusedLocation heading)이 다르면 지점을 다시 고릅니다.

## 한 번의 픽업 흐름

1. **정차 중**: 운전자가 화면에서 사람을 고르거나 "엄마 데리러 가자"라고 말합니다. 엄마 폰으로 링크가 갑니다.
2. **엄마가 링크를 열고 위치 공유에 동의하면**: 앱이 같은 편 지점을 고릅니다. 대중교통이 5분 넘게 빠르면 그 안도 엄마에게 보입니다.
3. **운전자 확인**: 정차 중에 한 번 확인하면 기본 내비 목적지로 들어갑니다.
4. **주행 중**
   - 운전자: 음성 알림만 받습니다.
   - 엄마 폰: 지점 사진, "차는 이쪽 길로 와서 여기 섭니다" 화살표, "4분 뒤 나오면 딱 맞아요"가 나옵니다.
5. **자동 전화**: 남은 시간이 엄마 걸음 + 1분이 되면 "엄마께 전화 걸게요"라고 말한 뒤 자동으로 겁니다.
6. **150m 앞**: "오른쪽 스타벅스 앞이에요." 엄마가 길 건너편에 있으면 엄마 폰에만 "앞 횡단보도를 건너 스타벅스 앞으로"가 뜹니다.
7. **지나치면**: 앞쪽 같은 편 지점으로 바꾸고 둘 다에게 알립니다(R3, 2차).
8. **탑승**: 조수석 문과 착좌가 바뀌면 "만났어요". 위치 공유가 끝납니다.

## 플랫폼에서 확인할 것

| 필요한 것 | 쓰는 것 | 확인할 것 |
|---|---|---|
| 지점을 내비에 넘기기, 남은 시간 | NaviHelper(목적지·경유지, TripInfo의 도착 예정 시간) | 경유지로 진입 방향을 고정할 수 있는지, 도착 시간이 얼마나 자주 갱신되는지 |
| 차의 진행 방향 | FusedLocation(heading, 지오펜스) | 에뮬레이터에서 GPX 경로를 재생하면 heading이 오는지 |
| 탑승 확인 | Vehicle SDK(문, 착좌, 기어) | 조수석 착좌 신호. 에뮬레이터에서 뒷좌석 착좌는 늘 켜져 있었습니다(첫 앱 검증) |
| 자동 전화 | 차에 연결된 폰으로 발신 | Pleos FAQ에 Telephony 제한 가능성이 있습니다. 자동 발신이 되는지 가장 먼저 확인합니다. |
| 음성 안내 | TTS | 주행 중 말하기. 주행 중에는 DO를 선언하지 않은 앱의 화면이 가려집니다(첫 앱 검증). |
| 장소, 자동차·대중교통 경로, 정차 금지 자리 | 외부 API와 공공데이터(장소 검색, 자동차 경로, 대중교통 경로, 주정차 금지·정류장·횡단보도 데이터) | 키, 비용, 약관. 1차 시연은 한 지역 데이터를 미리 준비합니다. |
| 태울 사람 화면 | 서버 + 모바일 웹 | 링크를 보내는 방법(문자 API, 운전자 폰에서 공유, QR) |

## 위험과 대응

| 위험 | 대응 |
|---|---|
| 자동 발신이 막힌다 | 태울 사람 폰이 전화처럼 울리며 "지금 나오세요"를 띄웁니다. 태울 사람이 누르면 운전자 폰으로 전화가 오고, 운전자는 핸들 버튼으로 받습니다. |
| 기본 내비가 다른 방향으로 데려간다 | 진입 경유지를 넣고, 300m 앞에서 방향을 다시 확인합니다(F1의 5). |
| GPS 오차로 길의 어느 편인지 잘못 본다 | 도로 가운데와 가까워 편이 애매한 후보는 뺍니다. 넓은 길과 역 앞에서는 출구 번호처럼 확실한 기준을 씁니다. |
| "마중과 같다"는 평가 | 기획서 첫 줄과 시연 첫 장면을 "같은 편"으로 합니다. 위치 공유는 기본 기능이라고 밝힙니다. |
| 위치 정보 | 픽업 중에만 동의를 받아 공유합니다. 탑승하거나 30분이 지나면 자동으로 끝내고, 서버에 이동 기록을 남기지 않습니다. |
| 외부 API 비용과 키 | 1차는 한 지역 데이터로 하고, 실시간 API는 2차에 붙입니다. |

## 제가 정한 기본값 (바꾸려면 알려 주세요)

- 걷는 거리: 300m 안(아이·어르신으로 표시한 사람은 150m)
- 대중교통 제안: 만나는 시각이 5분 넘게 빨라질 때만. 탈지 말지는 태울 사람이 고릅니다.
- 자동 전화: 남은 시간 ≤ 태울 사람 걸음 + 1분(최소 2분). 픽업마다 한 번만, 이미 나와 있으면 생략
- 주행 중 운전자에게는 음성만, 한 번에 한 줄
- 1차 시연 지역: 회의에 나온 수원역이나 성균관대역 주변 한 곳
- 작업 이름: 같은편(길의 같은 편 + 우리 편). 다른 후보는 한편, 이쪽편

## 1차(11/15) 시연 장면

1. **반대편 함정**: 그냥 가면 U턴해야 하는 자리에서, 앱이 차가 오는 쪽 출구 앞으로 바꿔 줍니다. 그래서 한 번에 탑니다.
2. **두 정거장 역마중**: 막히는 쪽에 있는 친구에게 "2정거장 타고 오면 8분 빨라요"를 제안하고, 친구가 받아들입니다.
3. **손 안 대는 도착**: 자동 전화 → "오른쪽 스타벅스 앞이에요" → 조수석 문·착좌 → "만났어요"와 위치 공유 종료
