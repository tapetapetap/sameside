# Contract: 화면과 음성

화면 색·글꼴·도우미는 DRIVE DNA의 `Ui.kt`와 색 토큰을 그대로 쓴다(plan "DRIVE DNA에서 가져오는 것").

**공통 규칙**
- **분 표시**: 차 화면과 페이지의 "n분"은 모두 초를 60으로 나눠 올림한다(data-model §8).
- **"(으)로"**: 앞말의 마지막 글자에 받침이 없거나 받침이 ㄹ이면 "로", 아니면 "으로"를 붙인다. 글자 "(으)로"를 그대로 보이거나 읽지 않는다.

## 1. 차 화면 (정차 중)

- 배치는 DRIVE DNA와 같다. 가로는 왼쪽 칸 3 : 오른쪽 칸 5, 세로는 위 오른쪽 칸 / 아래 왼쪽 칸이다.
- 버튼은 기어가 P일 때만 눌린다. P가 아니면 흐리게 그리고 누르기에 반응하지 않는다.

### 왼쪽 칸: 사람과 차

- **제목**: "데리러 갈 사람"
- **사람 줄**
  - 줄마다 이름, 가린 번호, 아이·어르신이면 칩 "가까이만"이 있다.
  - 가린 번호는 앞 3자리와 끝 4자리만 보이고 가운데를 `****`로 바꾼다(예: "010-****-5678", 10자리 "031-****-5678").
  - 줄을 누르면 그 사람으로 픽업을 시작한다. 진행 중인 픽업이 있으면 누르기에 반응하지 않는다.
- **"+ 사람 추가"**: 대화상자를 연다. 이미 20명이면 대화상자를 열지 않고 "최대 20명까지 저장해요"를 보인다.
  - 입력: 이름, 전화번호, 체크 "아이·어르신(가까운 곳만 찾아요)"
  - 저장할 때 data-model §1 검증을 한다. 틀리면 그 칸 아래에 "이름은 1~10자로 적어 주세요" 또는 "전화번호를 확인해 주세요"가 보인다.
- **"내 차"**: 차종, 색, 번호판, 내 번호를 입력한다. 태울 사람 화면에 보인다. 검증은 data-model §1이고, 번호가 틀리면 "전화번호를 확인해 주세요"가 보인다.

### 오른쪽 칸: 상황

| 상태 | 보이는 것 | 버튼 |
|---|---|---|
| 픽업 없음 | "누구를 데리러 갈까요?" / "왼쪽에서 사람을 고르면 링크를 만들어요" | — |
| `link` | QR(정사각 300dp) / 링크 글자 / 안내 한 줄(아래) | 픽업 취소 |
| `spots` | 제목 "만날 곳" | 카드마다 "이 자리로 갈게요" / 픽업 취소 |
| | 1순위 카드: 큰 글자 "○○ 앞", 이유 한 줄, "○○님 걸어서 n분 · 차 n분" | |
| | 대안 카드 2장: 작게, 같은 형식 | |
| | 대중교통 안이 있으면 "○○님께 버스 n정거장 안을 보냈어요". 받아들이면 카드는 정류장 근처 지점 하나만 남고, 문구가 "○○님이 ○○ 타고 와요"로 바뀐다 | |
| `nospot` | "가까운 곳에 같은 편 자리가 없어요" / "위치 공유는 이어서 해요" | 픽업 취소 |
| `going` | "○○님 · ○○ 앞 · n분" / "내비에 넣었어요. 출발하세요" | 픽업 취소 |
| `met` | "만났어요" / "위치 공유를 끝냈어요" | 확인(픽업 없음으로) |
| `canceled` | "픽업을 취소했어요" | 확인 |
| `stopped` | "○○님이 위치 공유를 껐어요" | 확인 |
| `expired` | "시간이 지나 위치 공유를 끝냈어요" | 확인 |

- **서버 연결 실패 띠**(위): "서버에 연결하지 못했어요 · 2초마다 다시 시도해요"
- **QR과 링크 글자**: 1차는 `http://localhost:8090/p/<id>`다(contracts/api.md 기본).
- **`link` 상태의 안내 한 줄**: 서버에서 읽은 값으로 고른다.

  위에서부터 처음 맞는 줄을 쓴다.

  | 조건 | 문구 |
  |---|---|
  | `consent: false` | "○○님이 위치를 공유하지 않았어요" |
  | `consent: true`이고 태울 사람 위치가 아직 없음 | "○○님 위치를 기다리고 있어요" |
  | `consent: true`이고 차 위치를 아직 모름 | "차 위치를 확인하고 있어요" |
  | 그 밖(`consent: null`) | "○○님이 링크를 열면 만날 곳을 골라요" |

## 2. 운전자 음성 (주행 중, 한 줄씩)

| 언제 | 문장 |
|---|---|
| 자동 전화(걸 수 있음) | "○○님께 전화 걸게요" |
| 자동 전화(걸 수 없음) | "○○님 폰으로 알렸어요" |
| 그 시점에 이미 나와 있음 / "나와 있어요"를 처음 누름 | "○○님이 나와 있어요" |
| "조금 늦어요"를 처음 누름 | "○○님이 조금 늦는대요" |
| 150m, 오른쪽 | "오른쪽 ○○ 앞이에요" |
| 150m, 왼쪽(반대 방향 진입) | "○○님이 길을 건너 오른쪽으로 와요" |
| 150m, 방향 모름 | "곧 ○○ 앞이에요" |
| 대중교통을 받아들임 | "○○님이 ○○ 타고 ○○로 와요" 또는 "…으로 와요"(공통 규칙) |
| 탑승 | "○○님이 탔어요" |

## 3. 태울 사람 화면 (`server/page.html`)

- 세로 폰 화면 기준이고, 글자는 크게 쓴다.
- 지도는 SVG 그림 하나다. 지점 앞 길 선, 차가 들어오는 방향 화살표, 지점 별, 내 위치 점을 그린다.
  - 차 점은 차가 지점에서 300m 안일 때만 그림에 넣는다. 밖이면 그림 아래에 "차 n분 · n.n km"를 쓴다.
  - 그림 범위는 그리는 점들의 경계 상자에 맞춘다.

| 상태 | 보이는 것 | 버튼 |
|---|---|---|
| 처음 | "○○님을 데리러 가요" / "위치를 공유하면 만나기 좋은 곳을 골라 드려요. 공유는 타면 저절로 끝나요." | 위치 공유하고 시작(누르는 즉시 `consent: true`를 보낸다) / 괜찮아요(누르면 `consent: false`를 보낸다) |
| 위치 오류(만날 곳을 고르기 전) | "위치를 받지 못했어요. 브라우저 위치 허용을 확인해 주세요" | 다시 시도 |
| 위치 오류(그 뒤) | 화면은 그대로 두고 띠 "위치를 받지 못하고 있어요. 브라우저 위치 허용을 확인해 주세요"(동의 뒤 다시 열면 위치 보내기를 저절로 켜므로, 그때 실패해도 만날 곳 안내를 가리지 않게, 코드 리뷰 반영) | — |
| 거절 | "위치를 공유하지 않았어요" | 다시 공유하기 |
| `link`(동의 뒤) | "만날 곳을 고르고 있어요" | 공유 끄기 |
| `spots` | "운전자가 만날 곳을 확인하고 있어요" / 1순위 "○○ 앞" | 공유 끄기 |
| `nospot` | "가까운 곳에 같은 편 자리가 없어요. 운전자가 직접 찾아갈게요" / "차 n분"(data-model §8) | 탔어요 / 공유 끄기 |
| `going` | 아래 목록 | 나와 있어요 / 조금 늦어요 / 탔어요 / 공유 끄기 |
| `met` | "만났어요 · 위치 공유를 끝냈어요" | — |
| `canceled` | "픽업이 취소됐어요" | — |
| `stopped` | "위치 공유를 껐어요" | — |
| `expired` | "시간이 지나 위치 공유를 끝냈어요" | — |
| 404 | "끝난 픽업이에요" | — |

**`going`에서 보이는 것**
- 큰 글자 "○○ 앞"
- 사진(있으면)
- 그림
- "차는 이쪽 길로 와서 여기 서요"
- 나갈 때 안내: "n분 뒤 나오면 딱 맞아요", 0 이하면 "지금 나오세요"
  - 대중교통을 받아들였으면 이 줄 대신 "○○ 타고 ○○에서 내려 ○○ 앞으로 와 주세요"를 계속 보인다.
- "차 n분 · 흰색 그랜저 12가 3456"

### 알림 띠 (위에 겹쳐 보인다)

**소리 준비**: 브라우저는 사용자가 한 번 누르기 전에는 소리를 내지 않는다.
- 보통 모드에서는 "위치 공유하고 시작"을 누를 때 소리를 준비한다(AudioContext를 만든다).
- `?sim=1` 모드는 동의를 스크립트가 넣으므로, 화면 위에 "소리 켜기" 버튼을 보인다. 시연하는 사람이 처음에 한 번 누른다.
- 동의한 뒤 페이지를 새로 열면 소리가 꺼진 채라 같은 "소리 켜기" 버튼을 보이고, 위치 보내기는 저절로 다시 켠다(코드 리뷰 반영).

| 조건 | 띠 | 소리·진동 |
|---|---|---|
| `outNow` | "지금 나오세요" + 버튼 "운전자에게 전화"(`tel:` 링크, 운전자 번호가 있을 때만) | 있음(삐 소리 3번, `navigator.vibrate`) |
| `wrongSide` | "앞 횡단보도를 건너 ○○ 앞으로 와 주세요". `crossOver`가 켜져 있으면 보이지 않는다(지점 쪽으로 오라는 말이 반대가 된다, 코드 리뷰 반영) | 없음 |
| `crossOver` | "차가 길 건너편으로 와요. 건너편에서 기다려 주세요"(건넌 뒤에도 맞는 말, 코드 리뷰 반영) | 있음(한 번) |

### 대중교통 카드 (`offer`가 있고 아직 고르지 않았을 때)

"버스 7번 2정거장 타고 ○○에서 내리면 8분 빨리 만나요"
- 버튼: 그렇게 갈게요 / 그냥 걸어갈게요
- 아래에 작게 "시연용 준비 데이터예요"를 둔다(1차).
