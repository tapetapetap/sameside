# Contract: 화면·음성 추가

1차 `specs/001-sameside-pickup/contracts/ui.md`에 더하거나 바꾸는 것만 적는다.

## 1. 차 화면 (정차 중)

| 어디 | 바뀌는 것 |
|---|---|
| `spots`의 지점 카드 | 비교 조건(data-model §2)이면 "○○님 걸어서 n분 · 차 n분" 아래에 작은 글자 "건너기 n분 · 유턴 m분" |
| `going` | 확인 카드가 떠 있으면 맨 위에 큰 카드: 제목 "도착했다고 알릴까요?", 버튼 "보내기"(파랑)·"아니요"(연한 파랑). 버튼은 P에서만 눌린다 |
| `going` | `lostDest`가 있으면 요약 아래 작은 글자 "원래 목적지(○○) 대신 만날 곳으로 안내해요" |

## 2. 운전자 음성 (1차 §2에 더하거나 바꿈)

| 언제 | 문장 |
|---|---|
| 자동 전화(걸 수 있음) | "○○님께 전화 걸게요" — **알림 뒤 60초에 반응이 없을 때만** |
| 자동 전화(걸 수 없음) | "○○님 폰으로 알렸어요" — 같은 때 |
| 150m, 오른쪽, 기준 랜드마크 있음 | "오른쪽 ○○ 지나서 △△ 앞에 세우세요" |
| 도착 확인 | "○○님께 도착했다고 알릴까요?" |
| 탑승, 원래 목적지 있음 | "○○님 탑승 확인. 다음 목적지로 안내할게요" |

알림 단계("지금 나오세요"를 보낼 때)에는 운전자 음성이 없다.

## 3. 태울 사람 화면 (`server/page.html`)

| 어디 | 바뀌는 것 |
|---|---|
| `outNow` 띠 | "지금 나오세요" 아래에 버튼 두 개. "지금 나가요"(`PUT {ack: true}`)와 1차의 "운전자에게 전화"(번호가 있을 때)다. `ack`가 true면 "지금 나가요" 대신 "운전자에게 나간다고 알렸어요" |
| 새 띠 `arrived` | "차가 도착했어요. ○○ 앞으로 오세요". `crossOver`면 "차가 길 건너편에 도착했어요. 가까운 횡단보도로 건너 주세요"(위임 결정 D1). 켜지는 순간 소리 2번 |
| `spots`·`going`의 지점 이름 아래 | 지점의 `fasterMin`(k)이 있으면 "{이름}님이 길을 건너는 게 차가 유턴하는 것보다 k분 빨라요". 태울 사람이 길을 건넌 뒤에는 차가 k를 지워 줄이 내려간다 |
| `going`의 "차는 이쪽 길로 와서 여기 서요" 다음 | 지점의 `standLine`("올리브영을 지나 세븐일레븐 앞 인도에 서 계세요" 또는 "세븐일레븐 앞 인도에 서 계세요") |

띠 순서(위에서부터): `arrived`, `outNow`, `crossOver`, `wrongSide`
