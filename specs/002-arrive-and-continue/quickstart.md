# Quickstart: 같은편 2차 검증

준비(에뮬레이터, 서버, `adb forward`, 콘솔 페이지 닫기)는 1차 `specs/001-sameside-pickup/quickstart.md`와 같다. 장면 공통 규칙도 같다. **장면은 늘 `reset` 뒤에 돈다.**

## 바뀐 `reset` (research R15, 위임 결정 D3)

1차 순서에 아래를 더한다.
1. 앱을 멈추기 전에 `DemoReceiver route`로 내비 목적지를 "시연대기"(37.3002852, 126.9711778, 공백 없음)로 넣는다.
2. 다시 쓰는 `people.xml`에 `navOwn`="시연대기"를 넣는다. 일반 장면은 목적지 방식으로 돈다.
3. 콘솔 깜빡이를 `Off`로 둔다.

## 바뀐 기대값 (1차 장면)

| 이름 | 바뀌는 것 |
|---|---|
| `handsfree`, `fallback` | 알림이 실제 문턱 뒤 30초 안에 한 번 뜬다. 전화(또는 대체 알림 음성)는 알림 뒤 60~62초에 한 번이다(SC-008). 페이지 문장은 "세븐일레븐 앞 인도에 서 계세요"다. 재는 법은 표 아래 |
| `opposite` | 1순위 카드에 "건너기 1분 · 유턴 m분"이 있고, 페이지에 "민지님이 길을 건너는 게 차가 유턴하는 것보다 (m−1)분 빨라요"가 있다. 150m 음성은 "오른쪽 올리브영 지나서 세븐일레븐 앞에 세우세요"다. 페이지의 서 있을 곳 문장은 "세븐일레븐 앞 인도에 서 계세요"다(민지가 세븐일레븐보다 북쪽). 확인 직후 문턱이라 알림이 바로 가고, 60초 안에 탑승하지 않으면 전화가 간다 |
| `wrongside` | 1차와 같다. "나와 있어요"를 눌렀으므로 알림·전화가 없다 |

`handsfree`·`fallback`에서 스크립트가 재는 값(출발 기준 초로 출력):
- 실제 문턱: 경로 길이와 속도로 계산한 "남은 시간 = 걷는 시간 + 60초"인 때
- 알림 시각: 서비스 로그 "알림 보냄"(기기 시각)
- 전화 시각: "말하기: 민지님께 전화 걸게요"(`handsfree`) 또는 "말하기: 민지님 폰으로 알렸어요"(`fallback`) 로그(기기 시각). 출발 시각도 기기 시각으로 잰다

## 새 장면 (`python3 scripts/demo.py <이름>`)

| 이름 | 하는 일 | 기대 결과 |
|---|---|---|
| `ack` | `handsfree`와 같게 달리다가, 서버 `outNow`가 켜지면 바로 `PUT {ack: true}` | 전화 0번(로그에 "전화 걸기 요청" 없음, `dumpsys telecom`에 새 통화 없음). 페이지 띠가 "운전자에게 나간다고 알렸어요"로 바뀐다. 탑승하면 "만났어요" |
| `arrive` | `opposite`의 차·경로를 쓰고, 민지는 올리브영 40m 남쪽 동쪽 인도(37.2979552, 126.9713407, scenes.txt `arrive passenger`)에 있다. 지점까지 달려 서고, 콘솔 `turn-signal?mode=BlinkRight`. 질문 음성이 나오면 P로 놓고 깜빡이를 끈 뒤 차 화면 "보내기"를 누른다(깜빡이를 켜 두면 에뮬레이터가 측방 카메라 창으로 화면 왼쪽을 가려 버튼이 눌리지 않는다, 구현 중 확인) | 페이지 서 있을 곳 문장 "올리브영을 지나 세븐일레븐 앞 인도에 서 계세요". 음성 "민지님께 도착했다고 알릴까요?" 한 번, 정차 뒤 8초 안(SC-010: 3초 정차 + 5초). 카드, 보내기 뒤 5초 안에 서버 `arrived: true`, 페이지 "차가 도착했어요. 세븐일레븐 앞으로 오세요". 그다음 탑승 |
| `continue` | `reset` 뒤 `DemoReceiver route`로 내비 목적지 "집"(화서역 37.2839144, 126.9896135)을 넣는다. 그다음 `opposite`처럼 픽업·탑승 | 확인 직후 `DemoReceiver state`: 목적지 "집", 경유지 `[진입, 세븐일레븐 앞]`. 탑승 음성 "민지님 탑승 확인. 다음 목적지로 안내할게요". 탑승 뒤 `state`: 목적지 "집", 경유지 `[]` |
| `continue-cancel` | `continue`처럼 "집"을 넣고 지점을 확인한 뒤, 출발하지 않고 P에서 "픽업 취소"(FR-035) | 취소 뒤 `state`: 목적지 "집", 경유지 `[]` |
| `continue-full` | "집"을 넣은 뒤 `DemoReceiver waypoint`로 경유지 하나(화서역 약국)를 더해 두고 지점을 확인한다(FR-037) | `state`: 목적지 "세븐일레븐 앞". 차 화면 going에 "원래 목적지(집) 대신 만날 곳으로 안내해요". P에서 취소하고 끝낸다 |
